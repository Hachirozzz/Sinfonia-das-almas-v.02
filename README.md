# Sinfonia das Almas

Sistema de RPG para **Foundry VTT v13+**.

Cada teste é resolvido por dois dados de atributo somados ao grau de maestria da
perícia. Por trás disso, a alma vive um cabo de guerra: cada vez que a
Determinação cede, a Corrupção avança — e quando ela transborda, fica uma marca
permanente.

---

## Instalar

No Foundry: **Game Systems → Install System → Manifest URL**, e cole:

```
https://github.com/Hachirozzz/Sinfonia-das-almas-v.02/releases/latest/download/system.json
```

Esse endereço aponta sempre para a versão mais recente.

---

## O que o sistema faz

- **Cinco atributos como dados** (d6 a d12), com PV, PE, Defesa, Iniciativa e
  ND Místico calculados sozinhos
- **30 perícias**, cada uma com os dois atributos editáveis na ficha
- **Rolagem completa**: ND, modificador situacional, Empenho, Força das Sombras
  e ativação de Origem, tudo numa janela só
- **Eixo da Alma automático**: perder Determinação gera Corrupção; encher a
  Corrupção dispara o Estilhaço da Alma
- **Origens** com trava de uma ativação por sessão
- **Itens**: armas, armaduras, escudos, conduítes mágicos, consumíveis, magias e
  habilidades com Nível de Habilidade

### Atalhos

| Atalho | Efeito |
| --- | --- |
| **Shift + clique** no nome da perícia | Rola direto, sem abrir a janela |
| **Shift + clique** em "Dano" | Rola já dobrado (crítico) |
| Arrastar item para a ficha | Adiciona ao personagem |
